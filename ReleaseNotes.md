## [0.1.0] — 2026-10-14

Initial release.

- **Start guide** (`docs/start/`): a seven-step getting-started tutorial for using Claude Code inside IntelliJ IDEA and other JetBrains IDEs.
  1. Install Claude Code
  2. Connect IntelliJ
  3. Your first session
  4. Teach Claude your project with `CLAUDE.md`
  5. Everyday workflows
  6. Customize: permissions, skills, agents, MCP
  7. Tips and troubleshooting
- **Documentation index** (`docs/README.md`): overview of the sections.
- **Repository setup**: `CLAUDE.md` guidance for future Claude Code sessions, and `.gitignore` rules for IntelliJ project files.
